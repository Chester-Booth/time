# Simple New Tab
A minimalist [extension](https://addons.mozilla.org/en-GB/firefox/addon/time-and-links-new-tab-page/) and [website](https://chester-booth.github.io/time/) to be a new tab page

## Features
- Customisable (position and size) clock and datew
- Customisable font and colours (text and background)
- Customisable shortcuts to open favourite websites, by clicking or a key
